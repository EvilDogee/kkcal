# NutriLens

Мобильный PWA-дневник питания в тёмном iOS-inspired glass UI. Можно разместить на GitHub Pages и установить на экран «Домой» iPhone.

## Что умеет

- Дневная цель калорий и макронутриентов (белки, жиры, углеводы).
- Фото с камеры iPhone или выбор изображения из галереи.
- AI endpoint для оценки блюда по фотографии, с проверкой и редактированием порции перед сохранением.
- Ручное добавление блюда, дневник, удаление записей.
- Учёт воды, недельная статистика и история.
- Экспорт данных в JSON.
- Локальное хранение данных в браузере и PWA-кэш оболочки.

## Публикация на GitHub Pages

1. Открой репозиторий **Settings → Pages**.
2. В разделе Build and deployment выбери **Deploy from a branch**.
3. Выбери ветку `main` и папку `/ (root)`, затем Save.
4. Дождись завершения публикации и открой адрес Pages, показанный в настройках.

После публикации открой страницу в **Safari на iPhone** → «Поделиться» → **На экран Домой** → «Добавить». Камера работает через HTTPS и после выдачи разрешения браузеру.

## Настоящий AI-анализ фото

GitHub Pages обслуживает статические файлы и не может безопасно хранить приватный API-ключ. В репозитории есть пример серверной функции для Cloudflare Workers: `api/worker.js`.

1. Создай Worker в Cloudflare и вставь код из `api/worker.js` (либо задеплой файл через Wrangler).
2. В настройках Worker добавь secret с именем `OPENAI_API_KEY` и значением своего ключа провайдера. Не коммить ключ в Git.
3. При желании задай переменную `OPENAI_MODEL`; по умолчанию используется `gpt-4.1-mini`.
4. Разверни Worker и скопируй его HTTPS URL.
5. В NutriLens открой **Настройки → AI-распознавание**, вставь URL Worker и сохрани.
6. Перейди в сканер, сфотографируй блюдо и нажми «Оценить калории с AI».

Worker принимает JSON `{ "image": "data:image/jpeg;base64,...", "description": "..." }` и возвращает `{ "food": { "name": "...", "kcal": 450, "p": 30, "f": 15, "c": 48, "weight": 300, "emoji": "🍽️", "confidence": "medium", "notes": "..." } }`.

**Перед публичным использованием:** CORS в примере открыт для демонстрации. Ограничь его доменом своего GitHub Pages, добавь rate limiting/защиту от злоупотреблений и лимиты расходов на AI-провайдера. Запросы могут тарифицироваться провайдером. Указанный код — стартовый пример, не production-защита.

## Важные ограничения

- Без настроенного AI endpoint приложение не распознаёт изображение нейросетью. В этом режиме доступна только приблизительная оценка по текстовому описанию/простому локальному справочнику — интерфейс явно сообщает об этом.
- Калорийность по фотографии всегда приблизительна: масло, соусы, ингредиенты и размер порции могут быть не видны. Перед сохранением проверяй результат.
- Дневник хранится локально в браузере на устройстве. Экспортируй данные для резервной копии.
- Это инструмент самоконтроля, не медицинская рекомендация.

## Структура

- `index.html` — интерфейс и клиентская логика.
- `manifest.webmanifest` — PWA-метаданные.
- `sw.js` — кэширование оболочки.
- `icon.svg` — иконка.
- `api/worker.js` — пример защищённого AI endpoint.
