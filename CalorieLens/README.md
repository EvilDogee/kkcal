# CalorieLens

Нативный SwiftUI-прототип дневника калорий с камерой и распознаванием изображения через Apple Vision.

## Сборка через GitHub Actions

1. Создайте GitHub-репозиторий и загрузите в него содержимое этой папки `CalorieLens` — папки `CalorieLens`, `project.yml` и `.github` должны находиться в корне репозитория.
2. Откройте вкладку **Actions** в GitHub и запустите workflow **Build iOS app** через **Run workflow**. Он также запускается автоматически при push в ветку `main`.
3. После завершения откройте запуск workflow и скачайте артефакт `CalorieLens-iOS-Simulator` из раздела Artifacts. Это сборка для симулятора iOS, не устанавливаемый на iPhone IPA-файл.

Для запуска на iPhone нужна подписанная сборка: учётная запись Apple Developer, сертификат и provisioning profile. В GitHub Actions их обычно добавляют в repository secrets, после чего workflow настраивают на архивирование и экспорт IPA.

## Локальная сборка

Откройте `project.yml` через XcodeGen (`xcodegen generate`), затем откройте созданный `CalorieLens.xcodeproj` в Xcode. Для проверки камеры запустите приложение на iPhone; в симуляторе камера недоступна.

## Что включено

- Экран дневной цели с прогрессом калорий и макронутриентов.
- Камера и классификация снимка через `VNClassifyImageRequest`.
- Оценка калорий для распознанной категории, редактирование размера порции и добавление в дневной счётчик.
- Светлая, тёмно-зелёная визуальная тема с крупными скруглениями и карточками.

Распознавание работает на устройстве и не отправляет фото на сервер. Vision классифицирует общие визуальные категории, а калорийность — демонстрационная оценка по справочнику; это не анализ состава или точное измерение порции. Данные дневника в прототипе хранятся только в памяти.
